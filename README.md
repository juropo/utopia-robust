# Two-stage robust multiobjective optimization with an application to forest management

The python notebook titled `robust_problem.ipynb` contains all the code used to in the case study. What each individual part is explained in the notebook itself. 

The data for forest management in all four scenarios used by the notebook is found in the folder `two_stage_data`. For the scenarios discussed in the paper, folder `l1l23` corresponds to scenario 1, folder `h1h23` to scenario 2, folder `l1h23` to scenario 3, and folder `h1l23` to scenario 4.
